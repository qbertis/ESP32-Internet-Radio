# ESP32 Internet Radio
---

## Загальний опис

ESP32 Internet Radio — це повнофункціональний інтернет-радіоприймач на базі мікроконтролера ESP32 та аудіо декодера VS1053b. Пристрій відтворює інтернет-радіостанції через Wi-Fi з'єднання, має OLED дисплей для відображення інформації, фізичні кнопки керування та веб-інтерфейс для розширеного налаштування.

## Апаратна частина

### Основні компоненти

| Компонент      | Модель                     | Призначення       
|----------------|----------------------------|-------------------
| Мікроконтролер | ESP32 (Dual-Core, 240 MHz) | Основний процесор 
| Аудіо декодер  | VS1053b                    | Декодування MP3/AAC/OGG потоків 
| Дисплей        | SH1106 128×64 OLED (I2C)   | Відображення інформації 
| Кнопки         | 6 шт., тактові             | Керування пристроєм 

### Схема підключення

#### OLED дисплей (I2C)

| Пін дисплея  | GPIO ESP32 | Опис                |
|--------------|------------|---------------------|
| SDA          | GPIO21     | Дані I2C            |
| SCL          | GPIO22     | Тактовий сигнал I2C |
| VCC          | 3.3V       | Живлення            |
| GND          | GND        | Земля               |

**Швидкість шини I2C:** 400 kHz

#### VS1053b аудіо модуль (SPI)

| Пін VS1053 | GPIO ESP32 | Опис 
|------------|------------|------
| MOSI       | GPIO23     | Дані SPI (Master → Slave) 
| MISO       | GPIO19     | Дані SPI (Slave → Master) 
| SCK        | GPIO18     | Тактовий сигнал SPI 
| CS         | GPIO5      | Chip Select (керування) 
| DCS        | GPIO16     | Data Chip Select (аудіо дані) 
| DREQ       | GPIO4      | Data Request (готовність) 
| VCC        | 5V         | Живлення 
| GND        | GND        | Земля 

**Швидкість SPI:** 1 MHz (команди), до 4 MHz (дані)

#### Кнопки керування

| Кнопка   | GPIO   | Функція | Опис 
|----------|--------|---------|------
| Кнопка 1 | GPIO13 | NEXT    | Наступна станція 
| Кнопка 2 | GPIO12 | PREV    | Попередня станція 
| Кнопка 3 | GPIO14 | VOL+    | Збільшити гучність / EQ+ 
| Кнопка 4 | GPIO27 | VOL-    | Зменшити гучність / EQ- 
| Кнопка 5 | GPIO26 | MUTE    | Вимкнення звуку 
| Кнопка 6 | GPIO25 | EQ MODE | Вхід/вихід з режиму еквалайзера 

**Тип підключення:** INPUT_PULLUP (кнопка замикає GPIO на GND)

```
ESP32 GPIO ──┤ ├── GND
           кнопка
```

## Функціонал

### Відтворення радіо

- Підтримувані формати: **MP3, AAC, OGG Vorbis**
- Підключення до станцій по HTTP (порт 80)
- FIFO буфер: **16 KB** (~1 секунда аудіо при 128 kbps)
- Автоматичний reconnect при втраті з'єднання
- Автоматичне перемикання на наступну станцію після 3 невдалих спроб
- Максимум станцій: **200**

### Еквалайзер (апаратний, VS1053b)

| Параметр | Діапазон     | Крок   | Частота            |
|----------|--------------|--------|--------------------|
| Bass     | 0 — +15 dB   | 1 dB   | 60 Hz (фіксована)  |
| Treble   | 0 — +10.5 dB | 1.5 dB | 10 kHz (фіксована) |

- Керування через кнопки та веб-інтерфейс
- Значення зберігаються в SPIFFS
- Застосування через прапор `eqNeedsUpdate` (без конфлікту SPI)

### Дисплей OLED

**Основний екран:**
```
┌────────────────────────────┐
│ 14:35:22          01.01.25 │
│                            │
│    ◄ Radio Roks UA ►       │  ← скрол назви
│                            │
│           Vol: 70          │
└────────────────────────────┘
```

**EQ екран:**
```
┌────────────────────────────┐
│ BASS<          >TREBLE     │
│ 8 dB            4.5 dB     │
│ ████░░           ███░░░    │
│                            │
└────────────────────────────┘
```

**Функції дисплея:**
- Скрол довгих назв станцій (відбивання від країв)
- Відображення часу та дати (NTP, оновлення раз на секунду)
- EQ режим з візуалізацією Bass/Treble
- Повідомлення (WiFi OK, Muted, EQ Exit тощо)
- Auto-dim через 60 секунд бездіяльності
- Auto-sleep через 3 хвилини бездіяльності
- Пробудження при натисканні будь-якої кнопки

### Кнопки керування

**Звичайний режим:**

| Кнопка        | Дія 
|---------------|-------------------
| NEXT (GPIO13) | Наступна станція 
| PREV (GPIO12) | Попередня станція 
| VOL+ (GPIO14) | Гучність +1 
| VOL- (GPIO27) | Гучність -1 
| MUTE (GPIO26) | Вмикання/вимикання звуку 
| EQ   (GPIO25) | Вхід в EQ режим (коротке натискання) 

**EQ режим:**

| Кнопка        | Дія 
|---------------|-----
| VOL+ (GPIO14) | Збільшити поточний параметр EQ 
| VOL- (GPIO27) | Зменшити поточний параметр EQ 
| EQ (GPIO25)   | Перемикання Bass ↔ Treble (коротке) 
| EQ (GPIO25)   | Вихід з EQ режиму (довге, >1 сек) 

**Автоматичний вихід з EQ режиму:** через 8 секунд бездіяльності

### Wi-Fi

- **WiFiManager** для першого підключення
- AP Mode при відсутності збереженої мережі:
  - SSID: `ESP32-Radio`
  - Пароль: `12345678`
  - IP: `192.168.4.1`
- Автоматичний reconnect кожні 10 секунд при втраті з'єднання
- Сканування доступних мереж через веб-інтерфейс
- Скидання Wi-Fi налаштувань через веб

### NTP (синхронізація часу)

- Сервери: `pool.ntp.org`, `time.nist.gov`
- Часовий пояс: `EET-2EEST` (Україна, Київ)
- Автоматичний перехід літній/зимовий час
- Інтервал синхронізації: 1 година

### Збереження налаштувань (SPIFFS)

Файл: `/radio_config.json`

**Що зберігається:**
- Список станцій (назва, хост, шлях)
- Номер поточної станції
- Гучність (0-100)
- Bass boost (0-15)
- Treble boost (0-7)

**Відкладене збереження:** через 2 секунди після останньої зміни (захист Flash від зносу)

## Веб-інтерфейс

### Сторінки

| URL       | Опис 
|-----------|------
| `/`       | Головна: керування радіо, EQ, станції 
| `/wifi`   | Налаштування Wi-Fi 
| `/system` | Системна інформація, OTA 
| `/update` | Оновлення прошивки через браузер 

### API Endpoints

| Endpoint                               | Метод | Опис                        |
|----------------------------------------|-------|-----------------------------|
| `/play?i=N`                            | GET   | Відтворити станцію N        |
| `/volume?val=N`                        | GET   | Встановити гучність (0-100) |
| `/volume?dir=up\|down`                 | GET   | Гучність ±5                 |
| `/mute`                                | GET   | Перемикання Mute            |
| `/eq?bass=N&treble=N`                  | GET   | Встановити EQ               |
| `/status`                              | GET   | JSON: стан пристрою         |
| `/save?i=N&name=...&host=...&path=...` | GET   | Зберегти станцію            |
| `/delete?i=N`                          | GET   | Видалити станцію            |
| `/add?name=...&host=...&path=...`      | GET   | Додати станцію              |
| `/stations/export`                     | GET   | Експорт станцій (JSON файл) |
| `/stations/import`                     | POST  | Імпорт станцій (JSON body)  |
| `/wifi/scan`                           | GET   | Сканування Wi-Fi мереж      |
| `/wifi/connect?ssid=...&pass=...`      | GET   | Підключення до мережі       |
| `/wifi/reset`                          | GET   | Скидання Wi-Fi налаштувань  |
| `/wifi/status`                         | GET   | JSON: стан Wi-Fi            |
| `/ota`                                 | POST  | Завантаження прошивки       |

### Головна сторінка — можливості

- Поточна станція з індикатором підключення
- Повзунок гучності з кнопкою Mute
- Повзунки Bass / Treble
- Таблиця станцій з підсвічуванням активної
- Редагування, видалення, додавання станцій
- Імпорт / Експорт списку станцій
- Авто-оновлення статусу кожні 3 секунди

### Системна сторінка

- Uptime
- Wi-Fi RSSI
- IP адреса
- Кількість станцій
- ESP32 модель та частота CPU
- Використання Heap (з прогрес-баром)
- Використання Flash (з прогрес-баром)
- SDK версія
- Кнопка OTA оновлення
- Кнопка Restart

### OTA оновлення

- Завантаження `.bin` файлу через браузер
- Прогрес-бар завантаження
- Автоматичне перезавантаження після успішного оновлення
- Захист від неправильних файлів

## Оновлення прошивки

### Через USB
1. Підключити ESP32 по USB
2. Arduino IDE → Upload

### Через OTA (по повітрю)
1. Arduino IDE → Sketch → Export Compiled Binary
2. Відкрити `http://<ip>/update`
3. Обрати файл `main.ino.bin`
4. Натиснути Upload & Flash
5. Дочекатися перезавантаження

## Блок-схема підключення

```
                    ┌──────────────┐
                    │    ESP32     │
                    │              │
    ┌───────────┐   │    GPIO21 ←──┼── SDA ──┐
    │  VS1053b  │   │    GPIO22 ←──┼── SCL ──┤ OLED
    │           │   │              │         │ SH1106
    │ MOSI ─────┼──→│ GPIO23       │         └────────┘
    │ MISO ─────┼──→│ GPIO19       │
    │ SCK  ─────┼──→│ GPIO18       ┌─── GPIO13 ── [NEXT]
    │ CS   ─────┼──→│ GPIO5        ├─── GPIO12 ── [PREV]
    │ DCS  ─────┼──→│ GPIO16       ├─── GPIO14 ── [VOL+]
    │ DREQ ─────┼──→│ GPIO4        ├─── GPIO27 ── [VOL-]
    │           │   │              ├─── GPIO26 ── [MUTE]
    │   OUT     │   │              └─── GPIO25 ── [EQ]
    └───────────┘   └──────────────┘
```
